  <name>Task 1: Create Claude API service with classification and routing</name>
  <files>src/services/claude.ts</files>
  <action>
    Create `src/services/claude.ts` with the following exports:

    **Setup:**
    - Import Anthropic from `@anthropic-ai/sdk`.
    - Import `config` from `../config/env`.
    - Instantiate the Anthropic client: `const anthropic = new Anthropic({ apiKey: config.anthropicApiKey })`.

    **classifyComplexity(message: string): Promise<"simple" | "moderate" | "complex">**
    - Call `anthropic.messages.create()` with:
      - model: `"claude-haiku-4-5-20251001"`
      - max_tokens: 10
      - system: `"Classify the complexity of the following user message as exactly one word: simple, moderate, or complex. Simple = factual questions, greetings, basic tasks. Moderate = analysis, comparison, multi-step reasoning. Complex = creative writing, deep research, expert-level problems. Respond with ONLY that single word, nothing else."`
      - messages: `[{ role: "user", content: message }]`
    - Extract the text from `response.content[0]` (assert type is "text").
    - Trim and lowercase the result. If it is not one of "simple", "moderate", "complex", default to "moderate".
    - Return the classification.

    **getModelForComplexity(complexity: "simple" | "moderate" | "complex"): string**
    - Map: `{ simple: "claude-haiku-4-5-20251001", moderate: "claude-sonnet-4-6", complex: "claude-opus-4-6" }`
    - Return the model ID string.

    **chat(messages: Array<{ role: "user" | "assistant"; content: string }>, model: string): Promise<{ content: string; tokensUsed: number }>**
    - Call `anthropic.messages.create()` with:
      - model: the passed model string
      - max_tokens: 4096
      - messages: the passed messages array
    - Extract text from `response.content[0]` (assert type is "text").
    - Calculate `tokensUsed = response.usage.input_tokens + response.usage.output_tokens`.
    - Return `{ content: text, tokensUsed }`.
  </action>

<task type="auto">
  <name>Task 2: Create message endpoint with full chat pipeline and mount routes</name>
  <files>src/routes/messages.ts, src/index.ts</files>
  <action>
    Create `src/routes/messages.ts` with an Express Router exporting `messagesRouter`.

    The router should use a base path that expects `conversationId` as a merge param. Set `{ mergeParams: true }` on the Router if mounting under conversations, OR define the full path. Choose the approach that works cleanest -- see mounting note below.

    **POST /conversations/:conversationId/messages** (authenticate, checkAccess)

    Full pipeline in order:

    1. **Record start time:** `const startTime = Date.now()`

    2. **Validate input:** Extract `content` from `req.body`. If missing or not a string, return 400 `{ error: "Message content is required" }`.

    3. **Verify conversation ownership:** Query `conversations` WHERE `id = req.params.conversationId AND user_id = req.user.id`. If no row, return 404 `{ error: "Conversation not found" }`.

    4. **Insert user message:** Insert into `messages` with `conversation_id`, `role = 'user'`, `content`, `model_used = NULL`, `tokens_used = NULL`. Use `RETURNING id, role, content, model_used, tokens_used, created_at`.

    5. **Load conversation history:** Query all messages for this conversation ordered by `created_at ASC`. Map to `Array<{ role: "user" | "assistant", content: string }>` for the Claude API call.

    6. **Classify complexity:** Call `classifyComplexity(content)` with the new user message text.

    7. **Route to model:** Call `getModelForComplexity(complexity)` to get the model ID.

    8. **Call Claude:** Call `chat(historyMessages, model)` with the full conversation history (including the just-inserted user message).

    9. **Insert assistant message:** Insert into `messages` with `conversation_id`, `role = 'assistant'`, `content = chatResult.content`, `model_used = model`, `tokens_used = chatResult.tokensUsed`. Use `RETURNING id, role, content, model_used, tokens_used, created_at`.

    10. **Auto-generate title on first message:** Check if this is the first user message in the conversation (e.g., check if the conversation title is NULL). If so, generate title from the first 50 characters of `content`, appending "..." if truncated. Update `conversations` SET `title = $1, updated_at = NOW()` WHERE `id = $2`.

    11. **Update conversation timestamp:** Always update `conversations` SET `updated_at = NOW()` WHERE `id = conversationId` (can combine with title update when applicable; otherwise separate query).

    12. **Deduct usage time:** Calculate `const elapsedSeconds = (Date.now() - startTime) / 1000`. Call `addUsage(req.user.id, elapsedSeconds)`.

    13. **Return response:** 201 with:
        ```json
        {
          "message": { "id", "role", "content", "model_used", "tokens_used", "created_at" },
          "model_used": "the-model-id",
          "tokens_used": 123
        }
        ```
        Where `message` is the assistant message row from step 9.

    Wrap the entire handler in try/catch, log errors with `console.error`, return 500.

    **Mounting in `src/index.ts`:**
    - Import `messagesRouter` from `./routes/messages`.
    - Mount as `app.use('/', messagesRouter)` since the route path in the router already includes `/conversations/:conversationId/messages`.
    - Alternatively, use `app.use('/conversations/:conversationId/messages', messagesRouter)` with `mergeParams: true` on the router and define the route as `POST /`. Choose whichever is cleaner -- the key requirement is that `POST /conversations/:conversationId/messages` works from the client perspective.
  </action>
