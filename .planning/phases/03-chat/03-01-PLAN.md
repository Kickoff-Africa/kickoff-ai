<task type="auto">
  <name>Task 2: Create conversation routes and mount in Express app</name>
  <files>src/routes/conversations.ts, src/index.ts</files>
  <action>
    Create `src/routes/conversations.ts` with an Express Router exporting `conversationsRouter`:

    **POST /** (authenticate middleware)
    - Insert a new row into `conversations` with `user_id = req.user.id` and `title = NULL`.
    - Use `gen_random_uuid()` for the id (PostgreSQL built-in).
    - Return 201 with `{ id, title, created_at }`.

    **GET /** (authenticate middleware)
    - Query conversations for `user_id = req.user.id`.
    - Use a LEFT JOIN or subquery on `messages` to get the timestamp of the last message as `last_message_at`:
      ```sql
      SELECT c.id, c.title, c.created_at,
        (SELECT MAX(m.created_at) FROM messages m WHERE m.conversation_id = c.id) AS last_message_at
      FROM conversations c
      WHERE c.user_id = $1
      ORDER BY c.updated_at DESC
      ```
    - Return 200 with array of `{ id, title, last_message_at, created_at }`.

    **GET /:id** (authenticate middleware)
    - First query `conversations` WHERE `id = $1 AND user_id = $2` (using req.params.id and req.user.id).
    - If no row found, return 404 `{ error: "Conversation not found" }`. This handles both non-existent and unauthorized access (no info leak).
    - Then query `messages` WHERE `conversation_id = $1` ORDER BY `created_at ASC`.
    - Return 200 with `{ id, title, created_at, messages: [{ id, role, content, model_used, created_at }] }`.

    All route handlers should be async and wrapped in try/catch returning 500 on unexpected errors.

    In `src/index.ts`:
    - Import `conversationsRouter` from `./routes/conversations`.
    - Add `app.use('/conversations', conversationsRouter);` after the existing route mounts.
  </action>
  <verify>
    - `npx tsc --noEmit` compiles without errors
    - `grep "conversationsRouter" src/index.ts` shows the mount
    - `grep "POST\|GET" src/routes/conversations.ts` shows all three route handlers
  </verify>
  <done>
    - POST /conversations creates a conversation and returns { id, title, created_at }
    - GET /conversations lists user's conversations with last_message_at
    - GET /conversations/:id returns conversation with full message history, 404 for non-owned
    - All routes require authentication
    - Router mounted in index.ts
  </done>
</task>
