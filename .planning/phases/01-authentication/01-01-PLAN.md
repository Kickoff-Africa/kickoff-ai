<task type="auto">
  <name>Task 2: Database connection and full v1 schema migration</name>
  <files>
    src/config/database.ts
    src/db/migrations/001_initial_schema.sql
    src/db/migrate.ts
    src/db/seed.ts

  <action>
    1. Create `src/config/database.ts`:
       - Import pg Pool
       - Create and export a Pool instance using DATABASE_URL from env config
       - Export a helper `query(text: string, params?: any[])` that calls pool.query

    2. Create `src/db/migrations/001_initial_schema.sql` with ALL v1 tables. Use UUIDs (gen_random_uuid()) for all primary keys. Add created_at/updated_at timestamps to all tables. Add appropriate indexes.

       Tables for Phase 1 (auth):
       ```sql
       CREATE TABLE users (
         id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
         email VARCHAR(255) UNIQUE NOT NULL,
         role VARCHAR(20) NOT NULL DEFAULT 'user' CHECK (role IN ('user', 'admin')),
         created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
         updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
       );

       CREATE TABLE magic_link_tokens (
         id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
         user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
         token VARCHAR(255) UNIQUE NOT NULL,
         expires_at TIMESTAMPTZ NOT NULL,
         used_at TIMESTAMPTZ,
         created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
       );

       CREATE TABLE user_sessions (
         id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
         user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
         jwt_jti VARCHAR(255) UNIQUE NOT NULL,
         created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
         expires_at TIMESTAMPTZ NOT NULL,
         revoked_at TIMESTAMPTZ
       );
       ```

       Tables for Phase 2 (access control):
       ```sql
       CREATE TABLE access_windows (
         id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
         user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
         window_start TIMESTAMPTZ NOT NULL,
         seconds_used INTEGER NOT NULL DEFAULT 0,
         created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
       );

       CREATE TABLE access_extension_requests (
         id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
         user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
         requested_hours INTEGER NOT NULL CHECK (requested_hours IN (1, 2, 3)),
         status VARCHAR(20) NOT NULL DEFAULT 'pending' CHECK (status IN ('pending', 'approved', 'denied')),
         reviewed_by UUID REFERENCES users(id),
         reviewed_at TIMESTAMPTZ,
         created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
       );
       ```

       Tables for Phase 3 (chat):
       ```sql
       CREATE TABLE conversations (
         id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
         user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
         title VARCHAR(255),
         created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
         updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
       );

       CREATE TABLE messages (
         id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
         conversation_id UUID NOT NULL REFERENCES conversations(id) ON DELETE CASCADE,
         role VARCHAR(20) NOT NULL CHECK (role IN ('user', 'assistant')),
         content TEXT NOT NULL,
         model_used VARCHAR(50),
         tokens_used INTEGER,
         created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
       );
       ```

       Add indexes:
       - users(email)  — already unique, but add explicit index
       - magic_link_tokens(token) — for lookup
       - magic_link_tokens(user_id) — for cleanup
       - user_sessions(jwt_jti) — for auth middleware lookup
       - user_sessions(user_id) — for listing/revoking sessions
       - access_windows(user_id, window_start) — for time lookups
       - access_extension_requests(user_id, status) — for listing pending
       - conversations(user_id) — for listing user conversations
       - messages(conversation_id) — for loading conversation history

    3. Create `src/db/migrate.ts`:
       - Reads all .sql files from src/db/migrations/ sorted by filename
       - Creates a `migrations` tracking table if not exists (name VARCHAR PRIMARY KEY, ran_at TIMESTAMPTZ)
       - For each migration not yet in the tracking table: execute it and record it
       - Logs each migration as it runs
       - Exits cleanly after completion

    4. Create `src/db/seed.ts`:
       - Import ADMIN_EMAIL from env config
       - INSERT the admin user with role='admin' using ON CONFLICT (email) DO NOTHING
       - Log whether the admin was created or already existed
       - Exit cleanly

    IMPORTANT: The seed script is separate from the migration. In Plan 01-02, the seed will also be called on server startup, but for now just make it a standalone script.
  </action>
