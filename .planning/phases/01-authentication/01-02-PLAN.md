  <action>
    1. Create `src/services/token.ts`:
       - `generateMagicToken()`: Returns a cryptographically random token using `crypto.randomBytes(32).toString('hex')`. No uuid here — use proper randomness.
       - `createJWT(userId: string, email: string, role: string)`: Creates a JWT with payload { sub: userId, email, role, jti: uuid() }. Sign with JWT_SECRET from env config. Set expiry from JWT_EXPIRY env var (default 24h). Return both the token string and the jti.
       - `verifyJWT(token: string)`: Verifies and decodes the JWT. Returns the decoded payload or throws.

    2. Create `src/services/email.ts`:
       - Configure nodemailer transport using SMTP env vars (SMTP_HOST, SMTP_PORT, SMTP_USER, SMTP_PASS)
       - `sendMagicLinkEmail(to: string, token: string)`: Constructs the magic link URL as `${APP_URL}/auth/verify?token=${token}`. Sends an email with subject "Your KickoffAI Login Link" and a simple HTML body containing the link. The link text should say "Click here to log in" and include a note that it expires in MAGIC_LINK_EXPIRY_MINUTES minutes.
       - In development (NODE_ENV !== 'production'), also log the magic link URL to console so testing works without real SMTP.

    3. Create `src/routes/auth.ts` with an Express Router exporting `authRouter`:

       **POST /auth/request-magic-link**
       - Accept { email: string } in request body
       - Validate email is present and is a non-empty string
       - Find or create user: INSERT INTO users (email) VALUES ($1) ON CONFLICT (email) DO UPDATE SET updated_at = NOW() RETURNING id, email, role
       - Generate magic token via generateMagicToken()
       - Store in magic_link_tokens: INSERT with user_id, token, expires_at = NOW() + MAGIC_LINK_EXPIRY_MINUTES minutes
       - Send email via sendMagicLinkEmail()
       - Return 200 { message: "Magic link sent to your email" } — do NOT reveal whether the user existed before
       - Wrap in try/catch, return 500 on failure

       **GET /auth/verify?token=xxx**
       - Read token from query string
       - Look up in magic_link_tokens WHERE token = $1 AND used_at IS NULL AND expires_at > NOW()
       - If not found or expired: return 400 { error: "Invalid or expired token" }
       - Mark token as used: UPDATE magic_link_tokens SET used_at = NOW() WHERE id = $1
       - Get the user from the token's user_id
       - Create JWT via createJWT(user.id, user.email, user.role)
       - Create session: INSERT INTO user_sessions (user_id, jwt_jti, expires_at) VALUES (user.id, jti, NOW() + JWT_EXPIRY)
       - Return 200 { token: jwtToken, user: { id, email, role } }

       **GET /auth/me** (protected — uses authenticate middleware)
       - Return 200 { user: { id, email, role } } from req.user (set by middleware)

       **POST /auth/logout** (protected — uses authenticate middleware)
       - Get jti from req.user (set by middleware)
       - UPDATE user_sessions SET revoked_at = NOW() WHERE jwt_jti = $1
       - Return 200 { message: "Logged out successfully" }

    4. Create `src/middleware/authenticate.ts`:
       - Export `authenticate` middleware function
       - Read Authorization header, expect "Bearer <token>" format
       - If missing: return 401 { error: "No token provided" }
       - Verify JWT via verifyJWT(). If invalid: return 401 { error: "Invalid token" }
       - Check session in DB: SELECT * FROM user_sessions WHERE jwt_jti = $1 AND revoked_at IS NULL AND expires_at > NOW()
       - If no valid session: return 401 { error: "Session expired or revoked" }
       - Fetch user: SELECT id, email, role FROM users WHERE id = decoded.sub
       - Set req.user = { id, email, role, jti } on the request object
       - Extend Express Request type using declaration merging in the same file or a types.d.ts file
       - Call next()

    5. Update `src/index.ts`:
       - Import authRouter, mount at root (so routes are /auth/*)
       - On startup (after DB connection verified), run the admin seed logic inline: INSERT INTO users (email, role) VALUES (ADMIN_EMAIL, 'admin') ON CONFLICT (email) DO NOTHING. Log whether admin was created or already existed.
       - Do NOT import seed.ts — embed the single INSERT query directly to keep startup simple.
  </action>
