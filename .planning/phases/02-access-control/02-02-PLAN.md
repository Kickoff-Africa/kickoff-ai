```typescript
export function requireAdmin(req: Request, res: Response, next: NextFunction): void {
  if (!req.user || req.user.role !== 'admin') {
    res.status(403).json({ error: 'Admin access required' });
    return;
  }
  next();
}
```

1. Create `src/routes/extensions.ts` with `export const extensionsRouter = Router()`:

   **POST /request** (protected: `authenticate`):
   - Body: `{ hours: number }` where hours must be 1, 2, or 3.
   - Validate: if hours is not 1, 2, or 3, return 400 `{ error: 'hours must be 1, 2, or 3' }`.
   - Check for existing pending request: `SELECT id FROM access_extension_requests WHERE user_id = $1 AND status = 'pending'`. If one exists, return 409 `{ error: 'You already have a pending extension request' }`.
   - Insert: `INSERT INTO access_extension_requests (user_id, requested_hours) VALUES ($1, $2) RETURNING id, requested_hours, status, created_at`.
   - Return 201 with the created request object (snake_case keys).

   **GET /pending** (protected: `authenticate`, `requireAdmin`):
   - Query: `SELECT r.id, r.user_id, u.email as user_email, r.requested_hours, r.status, r.created_at FROM access_extension_requests r JOIN users u ON r.user_id = u.id WHERE r.status = 'pending' ORDER BY r.created_at ASC`.
   - Return 200 with `{ requests: [...] }`.

   **POST /:id/approve** (protected: `authenticate`, `requireAdmin`):
   - Body: `{ hours: number }` where hours is 1, 2, or 3 (the actual granted amount, may differ from requested).
   - Validate hours same as above.
   - Find the request: `SELECT id, user_id, status FROM access_extension_requests WHERE id = $1`. If not found, return 404. If status !== 'pending', return 409 `{ error: 'Request is not pending' }`.
   - Update request: `UPDATE access_extension_requests SET status = 'approved', reviewed_by = $1, reviewed_at = NOW() WHERE id = $2` using [req.user!.id, requestId].
   - Add time to window: call `addExtensionToWindow(request.user_id, hours * 3600)` from access service.
   - Return 200 with `{ message: 'Extension approved', granted_hours: hours }`.

   **POST /:id/deny** (protected: `authenticate`, `requireAdmin`):
   - No body needed.
   - Find the request same as approve. If not found, 404. If not pending, 409.
   - Update: `UPDATE access_extension_requests SET status = 'denied', reviewed_by = $1, reviewed_at = NOW() WHERE id = $2` using [req.user!.id, requestId].
   - Return 200 with `{ message: 'Extension denied' }`.

   All endpoints wrapped in try/catch returning 500 on error. Import `authenticate` and `requireAdmin` from middleware, `query` from database config, `addExtensionToWindow` from access service.
