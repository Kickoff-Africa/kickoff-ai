  <name>Task 1: Migration and access service with time-window logic</name>
  <files>

    src/services/access.ts

  <action>
1. Create migration `src/db/migrations/002_add_extension_seconds.sql`:
   ```sql
   ALTER TABLE access_windows ADD COLUMN extension_seconds INTEGER NOT NULL DEFAULT 0;
   ```
   This column accumulates bonus seconds from approved extension requests.

2. Create `src/services/access.ts` with these exported functions:

   **`getOrCreateWindow(userId: string): Promise<AccessWindow>`**
   - Query: `SELECT * FROM access_windows WHERE user_id = $1 AND window_start > NOW() - INTERVAL '12 hours' ORDER BY window_start DESC LIMIT 1`
   - If no row found, INSERT a new one with `window_start = NOW()`, `seconds_used = 0`, `extension_seconds = 0` and RETURN it.
   - Return the row as `{ id, userId, windowStart, secondsUsed, extensionSeconds, createdAt }`.

   **`getRemainingSeconds(userId: string): Promise<{ secondsUsed: number; totalAllowed: number; secondsRemaining: number; windowStart: Date; windowExpiresAt: Date }>`**
   - Call `getOrCreateWindow(userId)`.
   - `totalAllowed = 3600 + window.extensionSeconds`
   - `secondsRemaining = Math.max(0, totalAllowed - window.secondsUsed)`
   - `windowExpiresAt = new Date(window.windowStart.getTime() + 12 * 60 * 60 * 1000)`
   - Return the computed object.

   **`addUsage(userId: string, seconds: number): Promise<void>`**
   - Get current window via `getOrCreateWindow(userId)`.
   - `UPDATE access_windows SET seconds_used = seconds_used + $1 WHERE id = $2` using [seconds, window.id].

   **`addExtensionToWindow(userId: string, extraSeconds: number): Promise<void>`**
   - Get current window via `getOrCreateWindow(userId)`.
   - `UPDATE access_windows SET extension_seconds = extension_seconds + $1 WHERE id = $2` using [extraSeconds, window.id].

   Define an `AccessWindow` interface at the top of the file. Use `import { query } from '../config/database'` for all DB calls. Use snake_case-to-camelCase mapping when reading rows.
  </action>
  <verify>

  </verify>

  <action>
1. Create `src/routes/access.ts`:
   - `export const accessRouter = Router()`
   - `GET /status` (protected with `authenticate` middleware):
     - Call `getRemainingSeconds(req.user!.id)`
     - Return 200 with JSON: `{ seconds_used, total_allowed, seconds_remaining, window_start, window_expires_at }`
     - Use snake_case keys in the JSON response for API consistency with the rest of the project.
     - Wrap in try/catch, return 500 on error.

2. Create `src/middleware/checkAccess.ts`:
   - `export async function checkAccess(req: Request, res: Response, next: NextFunction): Promise<void>`
   - Assumes `authenticate` has already run (req.user is set). If `!req.user`, return 401.
   - Call `getRemainingSeconds(req.user.id)`.
   - If `secondsRemaining <= 0`, return 429 with `{ error: 'Access time exhausted', seconds_used, total_allowed, window_expires_at }`.
   - Otherwise call `next()`.
   - This middleware does NOT deduct time — that happens after the chat completes (Phase 3 responsibility).

3. Update `src/index.ts`:
   - Add `import { accessRouter } from './routes/access'`
   - Add `app.use('/access', accessRouter)` after the auth router mount.
   - Do NOT mount checkAccess globally — it will be applied per-route in Phase 3 on the chat endpoint.
  </action>
