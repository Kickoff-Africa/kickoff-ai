**GET /users** (ADMN-01)
Single query joining users with aggregated stats:
```sql
SELECT
  u.id, u.email, u.role, u.created_at,
  COALESCE(aw.total_seconds_used, 0) AS total_seconds_used,
  aw.current_window_seconds_used,
  aw.current_window_start,
  COALESCE(mc.request_count, 0) AS request_count
FROM users u
LEFT JOIN LATERAL (
  SELECT
    SUM(seconds_used) AS total_seconds_used,
    (SELECT seconds_used FROM access_windows WHERE user_id = u.id ORDER BY created_at DESC LIMIT 1) AS current_window_seconds_used,
    (SELECT window_start FROM access_windows WHERE user_id = u.id ORDER BY created_at DESC LIMIT 1) AS current_window_start
  FROM access_windows WHERE user_id = u.id
) aw ON true
LEFT JOIN LATERAL (
  SELECT COUNT(*) AS request_count
  FROM messages m
  JOIN conversations c ON m.conversation_id = c.id
  WHERE c.user_id = u.id AND m.role = 'user'
) mc ON true
ORDER BY u.created_at ASC
```
Return 200 with `{ users: [...] }`. Each user object includes: id, email, role, created_at, total_seconds_used, current_window_seconds_used, current_window_start, request_count. Add a computed `current_window_expires_at` field: if current_window_start is not null, calculate `new Date(current_window_start).getTime() + 12 * 60 * 60 * 1000` and return as ISO string; otherwise null.

**GET /users/:userId/conversations** (ADMN-02 part 1)
Same pattern as GET /conversations but parameterized by :userId instead of req.user.id:
```sql
SELECT c.id, c.title, c.created_at,
       (SELECT MAX(m.created_at) FROM messages m WHERE m.conversation_id = c.id) AS last_message_at
FROM conversations c
WHERE c.user_id = $1
ORDER BY c.updated_at DESC
```
Return 200 with array of { id, title, last_message_at, created_at }.

**GET /conversations/:conversationId/messages** (ADMN-02 part 2)
No user_id ownership check -- admin can see any conversation:
```sql
SELECT id, role, content, model_used, tokens_used, created_at
FROM messages
WHERE conversation_id = $1
ORDER BY created_at ASC
```
First verify the conversation exists (SELECT id FROM conversations WHERE id = $1), return 404 if not found. Return 200 with `{ messages: [...] }`.

**GET /extensions** (ADMN-03)
Return all extension requests with requester and reviewer info:
```sql
SELECT
  r.id, r.user_id, u.email AS user_email,
  r.requested_hours, r.status,
  r.reviewed_by, rev.email AS reviewer_email,
  r.reviewed_at, r.created_at
FROM access_extension_requests r
JOIN users u ON r.user_id = u.id
LEFT JOIN users rev ON r.reviewed_by = rev.id
ORDER BY r.created_at DESC
```
Support optional query param `?status=pending|approved|denied`. If provided and valid, append `WHERE r.status = $1` to the query (adjust parameter numbering). If status param is present but not one of the three valid values, return 400 `{ error: 'status must be pending, approved, or denied' }`. Return 200 with `{ requests: [...] }`.

**PATCH /users/:userId/promote** (ADMN-04)
Accept body `{ role }`. Validate role is exactly "admin" or "user" -- if not, return 400 `{ error: 'role must be admin or user' }`. If userId equals req.user.id, return 400 `{ error: 'Cannot change your own role' }`. Execute:
```sql
UPDATE users SET role = $1, updated_at = NOW() WHERE id = $2 RETURNING id, email, role
```
If no rows returned, return 404 `{ error: 'User not found' }`. Return 200 with `{ user: { id, email, role } }`.
